#### 09:24

This morning in 2 hours I created two demos of a document analysis website for Frase.

The one by ChatGPT, in which I orchestrated everything and went through step by step, is definitely better then the one by Manus, which I did basically in one shot, especially considering that one shot resulted in PDF upload and parsing errors because it's a more complex setup.

Now that the PDF upload aspect is fixed, I think the main problem with the Manus version is actually that it doesn't have good reference documents.  All of its reference documents were created within that one shot, whereas with ChatGPT, we did a new "output step" to produce each of the PDFs.

ChatGPT already has a base that's designed to do exactly this kind of thing (uploading PDFs and parsing them).

Considering the quality of the reference documents, it's funny that
reference documents can be trivially changed in the ChatGPT demo
