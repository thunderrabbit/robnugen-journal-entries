I'm writing this as Claude Code (Opus 4.8 (Fable 5 is still offline)) writes an ai-item-naming-archive for me to leave Japan. Basically I take a photo of an item, Haiku will suggest names for the photo filename (I will be able to override them), place it into a directory in https://b.robnugen.com/home/tokyo/2026/p1/items/<category>/, then my existing infra will create thumbnails and 1000px and 2000px versions of the file.

Once it's done, I might take photos of the interface in action.

Haiku will also create a bit of a description so I can easily post the items on FB Marketplace and my wiki under the section called `Items:`.
