# The past few days (2026-04-14 through 2026-04-17)

## Agent Harness System (2026-04-14–15)

* Built a manifest-based agent launcher for Claude Code. Each agent gets a YAML file (~/.claude/agents/<name>.yaml) that defines its
MCP servers, identity, and launch directory. A shell wrapper (claude() function) auto-picks the right manifest based on $PWD and

(Vagrant) to manifests. Old hand-maintained .claude-mcp.json files deleted. Pre-commit hook runs a 13-test harness on every
commit to agents/ or bin/.

## auto_abbTester — First Autonomous Agent (2026-04-16–17)

* Designed and built a system where abbClaude can send a jikan message like "write a test for this endpoint" and a cron job on
Vagrant wakes auto_abbTester to do the work autonomously — no human terminal needed.

### What we built:

- Cron wrapper (auto-wake.sh) with 6 security review passes, 14 fixes — lock/heartbeat/reaper, budget cap ($0.50), PID tracking, stale-detection escalation
- Separate identities: auto_abbTester (does the work), auto_abbPoller (read-only inbox check) — distinct keys, distinct permissions
- System prompt with guardrails, "seek to understand not assume" philosophy, 5-message-per-session cap
- Guardrail gauntlet: 7 adversarial messages including prompt injection, trojan test file, impersonation, begging — all refused with correct reasoning
- Discovered --allowed-tools doesn't restrict built-in tools (only MCP), so guardrails are prompt-driven — and they hold

###  Architecture pivot mid-build: Started on rkan (Roots), switched to jikan (mg.robnugen.com) because jikan's inbox_visibility table supports cross-agent read access — the poller can see the tester's inbox without having the tester's key. This unlocked the security model we wanted.

## Jikan Agents API (2026-04-16)

* Built and deployed POST /api/v1/agents, /agents/keys, /agents/visibility on mg.robnugen.com — supervisor-only endpoints for programmatic agent creation. Security reviewed: blocked supervisor grants via API (web UI only), added 2-key-per-agent cap (AWS-style), name length validation. Used it to create 3 agents and configure visibility in minutes instead of clicking through the web UI.

## Jikan FIFO + Unseen Endpoint (2026-04-17)

* Changed inbox list sort from newest-first to oldest-first (FIFO) so auto_abbTester processes messages in order. Added 
PATCH `/inbox/mark-unseen` endpoint so stranded seen messages can be reset to pending.

## Lemur 13 + Lemur 10 Security Hardening (2026-04-17)

* First-ever network security audit of both machines. Found 4 services internet-facing on Lemur 13 via IPv6. In 15 minutes:

- OpenBrain (the thought database) bound to localhost — was on 0.0.0.0
- SSH bound to Tailscale only, password auth disabled, key-only
- rpcbind (port 111) disabled
- Apache default page disabled
- Synergy removed (never worked)
- Same treatment for Lemur 10: SSH Tailscale-only, epmd (Erlang) disabled
- Auth logs on both machines: clean. No unauthorized access ever recorded.
